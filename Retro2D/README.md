# Retro2D

为 4K / 5K / 8K 显示器上的 **1990 年代末～2000 年代 2D 游戏** 编写的 ReShade Shader。

当前版本：**v1.0**

---

# 目标

Retro2D **不是**完整 CRT 模拟器。它只做下列四件事：

1. 以「逻辑源分辨率」为基准**重建**低分辨率 2D 画面
2. 加入**亮度相关**的扫描束
3. 提供**可选**的极轻 RGB 栅罩
4. 全部参数都可以 A/B 关闭

它刻意**不做**：

```text
曲面屏幕（Curvature）
黑边 / 边框（Bezel）
暗角（Vignette）
Halation
Bloom
色散（Chromatic Aberration）
噪点 / 颗粒（Noise / Grain）
```

这样做的原因很直接：在 2D 游戏上，上面这些效果通常只会让原本干净的像素画变脏，而不是更像 CRT。

---

# 重要前提：ReShade 看不到原始低分辨率贴图

这是使用本 Shader 前必须理解的一点。

ReShade 处于渲染管线末端，只能看到**已经被放大后的最终 BackBuffer**。它拿不到 cnc-ddraw / RetroArch 那种真正的原始低分辨率 Source Texture。

所以：

```text
ReShade 无法恢复在它之前就已经被有损缩放丢掉的信息。
```

由此得到一条最重要的使用规则：

> 「逻辑源分辨率」要填写**游戏实际的逻辑画面分辨率**，
> 而不是最终的 4K BackBuffer 分辨率。

常见取值：

```text
640 x 480     2000 年前后 PC 2D 游戏最典型
800 x 600     后期 2D / 早期 3D 混合游戏
1024 x 768    较晚期的 2D 游戏
320 x 200     早期 DOS 风格
```

填写正确后，Shader 会按这个分辨率去「重新对齐」像素网格，扫描线密度也以它为基准——**而不是**以 4K 输出的 2160 行为基准。

如果源分辨率填错，最直观的表现是：像素网格和扫描线与游戏本身的像素块对不齐，出现明显的摩尔纹或粗细不均的条纹。

# 安装

复制到：

```text
游戏目录\
└─ reshade-shaders\
   └─ Shaders\
      └─ Retro2D.fx
```

Reload ReShade 后启用：

```text
Retro2D - 2D 游戏视觉优化
```

无需任何外部纹理。

# 推荐起点配置

先在「逻辑源分辨率」里选到游戏的真实分辨率（默认就是 `640 x 480`）。

## 640 x 480 游戏 + 4K 显示器

```text
逻辑源分辨率：640 x 480

内容区域：按源分辨率宽高比居中

回读 BackBuffer 采样：Linear

高质量 Lanczos 式横向重建：开

水平锐度：0.50

垂直锐度：1.00

边缘凝聚：1.00

扫描线强度：1.00

栅罩类型：关闭

整体效果强度：1.00
```

## 800 x 600 / 1024 x 768 游戏

只需要把「逻辑源分辨率」改成对应的值，其余保持默认。

源分辨率越高，扫描线会越密。若感觉过密：

```text
1024 x 768       扫描线强度可降到 0.5 ～ 0.7
1280 x 720 以上   已经会自动减弱，必要时再手动降低
```

## 如果游戏已经被拉伸到整个屏幕

```text
内容区域：整个 BackBuffer
```

这时 Shader 会把整个 BackBuffer 当作源画面做重建，不会再按比例居中。

## 如果黑边交给其他 Shader 处理

```text
内容区域：按源分辨率宽高比居中
```

Shader 只会处理中央游戏区域，viewport 之外的黑边原样返回，可以交给 AdaptiveBlur 系列去填充。

# 处理流程

```text
ReShade::BackBuffer（已放大的最终画面）
        ↓
计算内容区域 viewport
        ↓
viewport 之外            →  原样返回，不处理
        ↓
读取逻辑像素中心（Point / Linear 可选）
        ↓
边缘凝聚（像素混合域调整）
        ↓
横向重建：4 taps Lanczos 式  或  双线性式
        ↓
纵向重建：两行之间按垂直锐度插值
        ↓
输入 Gamma 映射
        ↓
亮度相关扫描束（绑定逻辑源分辨率）
        ↓
可选 RGB 栅罩（绑定输出像素）
        ↓
输出 Gamma + 亮度补偿
        ↓
按「整体效果强度」与原画面混合
```

几个关键设计点：

- **扫描线绑定源分辨率**：相位按 `localUV.y * 源高度` 计算，所以 640×480 的游戏在 4K 下依然是 480 条扫描束，不会因为更换显示器而变成 2160 条
- **亮度相关**：扫描束宽度随像素亮度在「最小 / 最大」之间插值；同时亮度越高，扫描线压暗越少，避免白色 UI 和人物高光被切掉
- **抗振铃**：4 taps 重建结果会被 clamp 到相邻两个采样点的 min / max 之间，抑制 Lanczos 过冲
- **亮度补偿**：只用于抵消扫描线和栅罩带来的平均亮度下降，**不产生** Bloom / Halation

# 参数说明

## 1. 源画面

### 逻辑源分辨率

选择游戏在被放大到 4K 之前的逻辑画面分辨率。

可选预设：

```text
320 x 200      320 x 240      400 x 300      512 x 384
640 x 400      640 x 480 ←推荐起点
720 x 480      720 x 576      800 x 600
1024 x 576     1024 x 768
1152 x 648     1152 x 864
1280 x 720     1280 x 768     1280 x 800     1280 x 960     1280 x 1024
1360 x 768     1366 x 768
1440 x 900     1600 x 900     1680 x 1050
1920 x 1080
自定义
```

### 自定义源宽度 / 自定义源高度

仅在「逻辑源分辨率 = 自定义」时生效。范围分别是 `160～2560` 与 `120～1600`，默认 `640` / `480`。

### 内容区域

| 选项 | 含义 |
|---|---|
| 整个 BackBuffer | 整个屏幕都当作游戏画面 |
| 按源分辨率宽高比居中（推荐） | 按源分辨率比例居中取一块区域，其余部分原样返回 |
| 按自定义宽高比居中 | 使用下方「自定义内容宽高比」的比例居中 |

本 Shader **不会主动制造 CRT 黑框**：viewport 之外的像素直接返回原画面。

例如 4:3 游戏在 16:9 屏幕中左右留黑边时，选择「按源分辨率宽高比居中」，Shader 就只会处理中央那块 4:3 区域。

### 自定义内容宽高比

仅在「内容区域 = 按自定义宽高比居中」时生效。范围 `1.0 ～ 2.5`，默认 `1.333333`。

```text
4:3   = 1.333333
16:10 = 1.6
16:9  = 1.777778
```

### 回读 BackBuffer 采样

| 选项 | 说明 |
|---|---|
| Point（更硬） | 最近邻回读，适合游戏本身已经是整数 / 最近邻缩放的情况 |
| Linear（推荐） | 双线性回读，更适合从非整数缩放的 4K 画面回读逻辑像素中心 |

---

## 2. 2D 图像重建

### 高质量 Lanczos 式横向重建

默认开启。

```text
开启：每条源扫描行使用 4 个横向采样点，轮廓更接近 cnc-ddraw 的 CRT EasyMode
关闭：使用较轻量的双线性式重建（2 个采样点）
```

### 水平锐度

范围 `0.00 ～ 1.00`，默认 `0.50`。

控制逻辑像素之间的横向重建曲线。`0` 更平滑，`1` 更接近硬像素。

### 垂直锐度

范围 `0.00 ～ 1.00`，默认 `1.00`。

控制相邻源扫描行之间的垂直重建。默认值可以保持较清晰的 2D 线稿。

### 边缘凝聚

范围 `0.00 ～ 1.00`，默认 `1.00`。

在重建前调整像素混合域，让老式 2D 线稿更凝练。`1.0` 接近 EasyMode 的默认行为；如果觉得深色轮廓过重，可以降低。

---

## 3. 扫描束

### 扫描线强度

范围 `0.00 ～ 1.00`，默认 `1.00`。

扫描线绑定的是**逻辑源分辨率**，不是 4K 输出像素，所以更换显示器或输出分辨率不会改变扫描线数量。

### 扫描束宽度 - 最小 / 最大

范围 `0.50 ～ 5.00`，默认都是 `1.50`。

数值越大，暗缝越窄。两者相同即可获得稳定、干净的扫描线；把最大值调高则可以让亮部使用更宽的电子束。

### 暗部扫描线亮度下限 / 亮部扫描线亮度上限

范围 `0.00 ～ 1.00`，默认分别是 `0.35` 与 `0.65`。

按像素亮度在这两个数值之间插值，决定该像素保留多少扫描线压暗：

```text
越暗的区域  →  越接近「下限」  →  扫描线越明显
越亮的区域  →  越接近「上限」  →  扫描线越轻，避免高光被切掉
```

### 扫描线相位

范围 `-0.50 ～ 0.50`，默认 `0.00`。

用于微调扫描线与逻辑像素中心的垂直对齐，通常保持 `0`。

### 高源分辨率自动减弱扫描线

默认开启。

对接近 1000p 以上的逻辑源画面自动减弱扫描线，避免高线数素材出现过密的纹理。`640x480`、`800x600`、`1024x768` 基本不受影响（减弱在源高度 900～1200 之间平滑过渡）。

---

## 4. 栅罩（可选）

### 栅罩类型

| 选项 | 说明 |
|---|---|
| 关闭（推荐默认） | 不叠加任何栅罩 |
| RGB Aperture Grille | 三通道横向循环 |
| RGB Staggered Mask | 在横向循环基础上按行错开 |

默认关闭，以避免 CRT_Lite 那种明显的 RGB 网格污染。

### 栅罩强度

范围 `0.00 ～ 0.50`，默认 `0.08`。

4K 原生显示时建议从 `0.05 ～ 0.12` 开始尝试。

### 栅罩尺寸

范围 `1.0 ～ 6.0`，默认 `1.0`。

每个 RGB 子栅格占用的输出像素尺寸。4K 通常使用 `1`。

### 8K 自动放大栅罩

默认开启。输出高度接近 4320 时自动把栅罩物理尺寸约放大一倍，避免 8K 下细得看不见。

### 栅罩亮度补偿

默认开启。对 RGB 栅罩造成的平均亮度损失做近似补偿。

---

## 5. 色调与输出

### 输入 Gamma

范围 `1.00 ～ 3.00`，默认 `2.00`。

EasyMode 风格默认值。重建阶段在这个域里进行。

### 输出 Gamma

范围 `1.00 ～ 3.00`，默认 `1.80`。

默认 `1.80` 会略微提亮中间调，接近 EasyMode 的观感。如果希望更忠实于原画，可以提高到 `2.0 ～ 2.2`。

### 整体亮度补偿

范围 `0.80 ～ 1.40`，默认 `1.08`。

仅用于补偿扫描线造成的亮度下降，不产生 Bloom / Halation。默认值比原版 EasyMode 更克制，避免白色 UI 过曝。

### 整体效果强度

范围 `0.00 ～ 1.00`，默认 `1.00`。

```text
0.00 = 原始 BackBuffer（完全关闭）
1.00 = 完整 Retro2D 效果
```

用于快速 A/B 对比，确认这个 Shader 到底带来了什么变化。

# Technique 顺序

建议放在主体画质 Shader **之前**，因为它需要读取接近原始的游戏画面来做重建：

```text
原始游戏
   ↓
Retro2D          ← 重建 + 扫描线
   ↓
色彩 / 锐化等 Shader
   ↓
AdaptiveBlur     ← 可选：填充黑边
```

实际顺序可以按自己的 ReShade Preset 调整。需要注意的是，如果先做锐化再做 Retro2D，扫描线和栅罩会被后续锐化放大，容易出现不自然的网格感。

---

# 与 AdaptiveBlur 搭配

Retro2D 的「内容区域」设为 **按源分辨率宽高比居中** 时，它只在中央游戏区域内工作，viewport 之外的黑边原样保留。这时可以再启用 `AdaptiveBorderBlur.fx` 或 `AdaptivePillarboxBlur.fx`，用游戏画面的实时高斯模糊延伸去填充这些黑边：

```text
┌───────────┬─────────────────────┬───────────┐
│           │                     │           │
│ 动态高斯模糊 │  2D 重建 + 扫描线    │ 动态高斯模糊 │
│           │                     │           │
└───────────┴─────────────────────┴───────────┘
   AdaptiveBlur         Retro2D        AdaptiveBlur
```

这样 4:3 老游戏放在 16:9 / 21:9 / 32:9 显示器上，就能同时获得「中央像素准确的 2D 扫描线画面」与「两侧动态环境模糊背景」。

# 性能

- 单 Pass，无需中间渲染目标
- 每像素最多 4 次横向 × 2 行 = 8 次 BackBuffer 采样（高质量模式）
- 关闭「高质量 Lanczos 式横向重建」后减少到 4 次采样
- 扫描线和栅罩都是纯算术运算，开销很小

在 4K / 5K / 8K 下都属于轻量级 Shader。

---

# 已知限制

- **无法恢复已丢失的信息**：如果游戏在 ReShade 之前就已经被有损放大，源分辨率填得再准也不会变回原始像素
- **不检测游戏真实分辨率**：源分辨率必须手动指定，因为从像素自动猜测 2D 游戏的逻辑分辨率并不可靠
- **栅罩以输出像素为基准**：栅罩相位基于输出分辨率，不随逻辑源分辨率变化，因此在 8K 下需要靠「8K 自动放大栅罩」来保持可见
- **不处理黑边**：viewport 之外的区域一律原样返回，黑边请交给 AdaptiveBlur 之类的 Shader
- 当前版本号为 `v1.0`，参数默认值仍可能继续调整
